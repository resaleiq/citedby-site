## Which to pick

If you have a team that will read a dashboard every week, a monitoring tool fits. If you run a small shop and want to know whether you are named and what to change, start with a site audit and decide after. CitedBy is at citedby.eu; it is not citedby.co.

## FAQ

### Do I need a monitoring dashboard?
Only if someone will read it every week. A one-off audit with fixes suits a small shop better.

### Why no prices for Profound?
Its own site showed no public price on 18 October 2026, so we do not quote one.
