CitedByBot

CitedByBot is the crawler behind CitedBy site audits. Its User-Agent header is:

CitedByBot/1.0 (+https://citedby.eu/bot)

When it visits

Only when a site owner or a visitor asks CitedBy to audit that site. It does not crawl on its own, and it does not build an index or a dataset of the web.

How it behaves

  • It reads your robots.txt first and obeys it. It follows the group User-agent: CitedByBot and, if there is none, the group User-agent: *.
  • It waits at least 1 second between requests to your site.
  • It stops at a page limit set by the plan of the audit: 25, 250 or 1,000 pages.
  • It only reads public pages. It does not log in, submit forms or run scripts.

Block it

Add this to your robots.txt and it will not fetch any page:

User-agent: CitedByBot
Disallow: /

To keep it out of one folder only, use Disallow: /folder/ instead.
