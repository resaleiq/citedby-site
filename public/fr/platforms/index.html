Autoriser ou bloquer les robots d'exploration IA sur 13 plateformes de sites

Une page par plateforme : où sa propre page d'aide place le réglage, ce qu'il couvre et ne couvre pas, et ce que seule cette page dit, chaque point lu à la date indiquée.

Chaque page nomme la page d'aide de la plateforme, l'endroit du réglage des robots IA, ce qu'il couvre et ce qu'il ne couvre pas : Adobe Commerce , Cloudflare , Framer , Ghost , Netlify , PrestaShop , Shopify , Squarespace , Vercel , Webflow , Wix , WordPress.com , WP Engine .

  • Adobe Commerce : robots.txt dans Content, Design, ConfigurationAdobe Commerce modifie robots.txt dans l'Admin, sous Search Engine Robots. Les projets Cloud ajoutent des étapes pub/media, et Adobe ne nomme aucun robot IA.Vérifié le 2026-10-24
  • Cloudflare : politiques des bots IA Search, Agent et TrainingCloudflare classe les bots IA en Search, Agent et Training, avec Block, Block on pages with ads et Allow. Nouvelles valeurs par défaut dès le 15 sept. 2026.Vérifié le 2026-10-21
  • Framer : importez votre propre robots.txt avec Static FilesFramer génère un robots.txt pour chaque site publié. Pour le changer, importez le vôtre via Static Files sur Pro ou Enterprise : il remplace le fichier généré.Vérifié le 2026-10-24
  • Ghost : ajoutez robots.txt à votre thème pour gérer les robots IAGhost n'a pas de réglage robots.txt dans l'admin. Selon son aide, un robots.txt à la racine du thème remplace celui par défaut. Offre requise sur Ghost(Pro).Vérifié le 2026-10-24
  • Netlify : robots.txt et User Agent Blocker contre les robots IANetlify n'a pas de réglage robots.txt : servez un fichier depuis la racine du site, ou installez User Agent Blocker. Son guide dit d'utiliser les deux.Vérifié le 2026-10-24
  • PrestaShop : un seul jeu de règles robots.txt pour tous les botsLe guide de PrestaShop décrit un bouton Generate robots.txt qui remplace votre fichier et n'utilise que User-agent: *. Ajoutez les règles IA ensuite.Vérifié le 2026-10-24
  • Shopify : gérez les robots IA et ce que robots.txt ne couvre pasModifiez robots.txt.liquid pour gérer les robots IA sur Shopify. Shopify dit qu'un blocage n'affecte que le web ouvert, pas les données produit pour ChatGPT.Vérifié le 2026-10-21
  • Squarespace : la case des robots IA bloque 26 bots, pas ChatGPTLe panneau Crawlers de Squarespace a une case qui bloque les robots IA connus. Les 26 noms omettent les bots de recherche et utilisateur de ChatGPT.Vérifié le 2026-10-21
  • Vercel : le jeu de règles AI Bots dans le Firewall (Log ou Deny)Vercel bloque les bots IA via un jeu de règles du Firewall, pas robots.txt : où est l'AI Bots Ruleset, les actions Log et Deny, et sa liste de bots à jour.Vérifié le 2026-10-24
  • Webflow : règles robots.txt et en-tête Content-Signal pour l'IAOù se trouve l'éditeur robots.txt de Webflow, l'offre requise, et comment l'en-tête Content-Signal sépare entraînement IA, recherche et entrée IA.Vérifié le 2026-10-21
  • Wix : bloquez les robots IA dans Robots.txt Editor (quatre noms)La page d'aide de Wix dit de coller quatre user agents dans le Robots.txt Editor. Où se trouve l'éditeur, ce que l'exemple omet et l'option nosnippet.Vérifié le 2026-10-21
  • WordPress.com : refus de l'IA via confidentialité, pas robots.txtWordPress.com traite le refus de l'IA comme « Prevent third-party sharing » dans la confidentialité. Ce que dit son guide, relu le 5 octobre 2026.Vérifié le 2026-10-21
  • WP Engine : robots.txt, crawl-delay de 10 s par défaut, Web RulesSelon WP Engine, un robots.txt physique l'emporte sur les fichiers de plugin et fixe un crawl-delay de 10 secondes. Web Rules Engine refuse les bots par agent.Vérifié le 2026-10-24
