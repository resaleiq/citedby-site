Lighthouse añade una categoría de navegación agéntica con una auditoría de llms.txt

7 may 2026 · Lighthouse · Fuente Lighthouse v13.3.0 release notes (GoogleChrome/lighthouse) · Leído el 22 oct 2026

“New agentic browsing category added to default config”

Cita (texto original)

Qué puedes hacer. Haz que /llms.txt responda 200 o 404, nunca con un error de servidor: Lighthouse marca los errores de servidor y trata un 404 como No aplicable.

Qué comprueba CitedBy: Comprobado en parte En parte. Cada rastreo pide /llms.txt: un 200 cuenta como presente, un 404 o 410 como ausente (un aviso opcional). CitedBy no marca como problema un error de servidor en ese archivo. Comprueba el tuyo gratis: verificador de llms.txt

Google documenta un límite de 2 MB por URL para Googlebot

31 mar 2026 · Google Search · Fuente Google Search Central Blog · Leído el 22 oct 2026

“Googlebot currently fetches up to 2MB for any individual URL (excluding PDFs).”

Cita (texto original)

Qué puedes hacer. Mantén el HTML de cada página por debajo de 2 MB y pon el título, el canonical y los datos estructurados clave al principio; traslada el CSS y el JavaScript integrados (inline) pesados a archivos externos.

Qué comprueba CitedBy: Comprobado Comprobado. CitedBy avisa cuando el HTML supera 1 MB, muy por debajo del límite de Google. Mide el HTML de cada página rastreada, para cualquier rastreador, no solo Googlebot.
