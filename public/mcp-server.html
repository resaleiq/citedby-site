CitedBy in your AI tools

CitedBy runs as an MCP server. Add it to Claude, ChatGPT, Cursor or Codex and ask the assistant to check a page, see which AI crawlers a site lets in, read its llms.txt, or list the domains that link to it. It is free, needs no account and only reads.

Connect it

The server address is https://citedby.eu/mcp (MCP Streamable HTTP, no sign-in).

  • Claude Code: claude mcp add --transport http citedby https://citedby.eu/mcp
  • Claude on the web and desktop: Settings, Connectors, Add custom connector, and paste the address.
  • Cursor: add CitedBy to Cursor, or put {"mcpServers":{"citedby":{"url":"https://citedby.eu/mcp"}}} in ~/.cursor/mcp.json.
  • Codex: codex mcp add citedby --url https://citedby.eu/mcp
  • Any other MCP client: add a remote server with the address above.

What it can do

ToolWhat you get
check_pageOne page, fetched as CitedBot: what is wrong for AI answers and search (title, description, headings, structured data, canonical, language, links), each with why it matters and the exact fix.
check_ai_crawler_accessFor GPTBot, OAI-SearchBot, ChatGPT-User, PerplexityBot, ClaudeBot, Google-Extended, Bingbot and Googlebot: allowed by robots.txt, and answered by the server, or not.
check_llms_txtWhether /llms.txt exists, whether its links work, and whether /llms-full.txt exists.
backlinksHow many domains link to a domain, and the strongest ones, from the Common Crawl web graph. It says when a domain is not in the data.

Ask it like this

  • "Check https://example.com/pricing with CitedBy and tell me what to fix first."
  • "Can GPTBot and PerplexityBot read example.com?"
  • "Does example.com have a working llms.txt?"
  • "Which domains link to example.com?"

Limits and rules

  • Pages are fetched as CitedBot. It reads robots.txt first and obeys it; a page it may not fetch is reported as not fetched, never guessed.
  • When a site refuses the crawler or does not answer, the tool says that instead of scoring the page.
  • check_page is one page with deterministic checks. A whole-site audit, with every page up to your plan's limit and the exact fix for each, is on the plans page.
  • 40 checks an hour from one address. Results are kept for an hour.
  • Nothing is written to your site, and nothing here asks who you are.
