How to allow or block AI crawlers on 13 site platforms

One page per platform: where its own help page says the setting lives, what it does and does not cover, and the one thing that page says that the others do not, each read on the date shown.

Each page names the platform's own help page, where the AI-crawler setting sits, what it covers and what it does not: Adobe Commerce, Cloudflare, Framer, Ghost, Netlify, PrestaShop, Shopify, Squarespace, Vercel, Webflow, Wix, WordPress.com, WP Engine.

  • Adobe Commerce: robots.txt is in Content, Design, ConfigurationAdobe Commerce edits robots.txt in the Admin under Search Engine Robots. Cloud projects add pub/media steps, and Adobe's pages name no AI crawler.Reviewed on 2026-10-24
  • Cloudflare: AI bot policies for Search, Agent and TrainingCloudflare's Block AI Bots page splits AI bots into Search, Agent and Training with Block, Block on pages with ads and Allow. New defaults from 15 Sept 2026.Reviewed on 2026-10-21
  • Framer: upload your own robots.txt with Static FilesFramer generates a robots.txt for every published site. To change it, upload your own through Static Files on Pro or Enterprise, which replaces it.Reviewed on 2026-10-24
  • Ghost: add robots.txt to your theme to allow or block AI crawlersGhost has no robots.txt setting in the admin. Its help says to save a robots.txt in your theme's root, which replaces the default. Plan needed on Ghost(Pro).Reviewed on 2026-10-24
  • Netlify: block AI crawlers with robots.txt and User Agent BlockerNetlify has no robots.txt setting: serve a file from your site root, or install the User Agent Blocker extension. Netlify's guide says to use both.Reviewed on 2026-10-24
  • PrestaShop: robots.txt generator writes one rule set for all botsPrestaShop's guide describes a Generate robots.txt button that replaces your file and uses User-agent: * only. Add AI crawler rules after generating.Reviewed on 2026-10-24
  • Shopify: allow or block AI crawlers, and what robots.txt missesEdit robots.txt.liquid to allow or block AI crawlers on Shopify. Shopify says a block affects open-web discovery only, not product data sent to ChatGPT.Reviewed on 2026-10-21
  • Squarespace: the AI crawler box blocks 26 bots but not ChatGPTSquarespace's Crawlers panel has one box blocking known AI crawlers. The 26 names it writes to robots.txt leave out ChatGPT's search and user bots.Reviewed on 2026-10-21
  • Vercel: the AI Bots ruleset in the Firewall (Log or Deny)Vercel blocks AI bots with a Firewall ruleset, not a robots.txt line. Where the AI Bots Ruleset is, the Log and Deny actions, and its self-updating bot list.Reviewed on 2026-10-24
  • Webflow: robots.txt rules and the Content-Signal header for AIWhere Webflow's robots.txt editor is, which plan it needs and how its Content-Signal header separates AI training, search and AI input.Reviewed on 2026-10-21
  • Wix: block AI crawlers in the Robots.txt Editor (four names)Wix's help page tells you to paste four user agents into the Robots.txt Editor. Where the editor is, what the example leaves out and the nosnippet option.Reviewed on 2026-10-21
  • WordPress.com: AI opt-out is a privacy setting, not robots.txtWordPress.com treats AI opt-out as 'Prevent third-party sharing' under privacy settings. What its site-visibility guide says, reviewed 5 October 2026.Reviewed on 2026-10-21
  • WP Engine: robots.txt, 10-second default crawl-delay, Web RulesWP Engine's help page says a physical robots.txt overrides plugin files and sets a 10-second default crawl-delay. Web Rules Engine denies bots by user agent.Reviewed on 2026-10-24
